Sample article

Loops and VEX in a Houdini network

Imagine this is your portfolio or blog. Below the text you would normally show a screenshot of your node network. With NOP your readers get the real network instead: they can move around, zoom in, open subnetworks and read every parameter and VEX snippet, on desktop and on their phones.

The loop

Boxes are copied onto scattered points, then a For-Each block works on every piece on its own. The tinted block shows which nodes run once per piece. Click twist_piece to see its parameters.

The code

Readers can open every wrangle and read its VEX in the colors of Houdini's own editor, instead of squinting at a screenshot. Click wrangle_rings to read its code.

How this page does it

One script tag on the page, then one <houdini-network> tag per network, pointing at the file exported from Houdini: the code under each network above. The viewer draws inside its own Shadow DOM, so the styles of your site and of the network never mix. During the tester phase the script is not on npm yet; the iframe tab has a version that works today.
